# 👑 ㄅㄆㄇ 夢幻打字魔法 (Bopomofo Magic Typing)

這是一個專為兒童設計的注音符號打字練習網頁小遊戲！透過可愛的介面與即時回饋，讓學習注音位置變得更有趣。

## 🎮 立即遊玩 (Play Now)

👉 **[點擊這裡開始挑戰](https://cuttlelin.github.io/Bopomofo/)**

## ⚠️ 重要操作說明 (Important)

**請務必注意：**
在開始遊戲前，**請將電腦的輸入法切換為「英文模式 (Eng)」**。
* 因為遊戲是偵測鍵盤的按鍵位置 (例如按 `1` 代表 `ㄅ`)，如果使用中文輸入法，按鍵會被攔截變成選字視窗，導致遊戲無法反應。

## ✨ 遊戲特色

* **粉嫩夢幻風格**：色彩繽紛的介面，吸引小朋友的注意力。
* **多種挑戰模式**：
    * ⏱️ 自選時間：60秒、120秒、或不限時練習。
    * 🔤 自選範圍：可針對「聲母」、「韻母/介音」、「聲調」或「標點符號」單獨練習。
* **即時回饋系統**：
    * 答對有星星特效 ✨
    * 答錯會有震動提醒 📳
* **成果統計**：挑戰結束後會顯示準確率、打字速度 (SPM) 以及星級評分 (最高 3 顆星 ⭐⭐⭐)。

## 🛠️ 本地執行 (Local Installation)

如果您想在自己的電腦上修改或執行此專案：

1.  將此專案 Clone 下來，或直接下載 ZIP 檔。
2.  找到 `index.html` 檔案。
3.  直接使用瀏覽器 (Chrome, Edge, Safari 等) 開啟即可遊玩，無需安裝任何伺服器軟體。
